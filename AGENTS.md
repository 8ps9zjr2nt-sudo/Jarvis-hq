# Jarvis HQ: AI Development Instructions

## Mission
Build a private, iPhone-first personal assistant that helps me manage everyday life gently and efficiently.

## Core principles
- Keep everything simple, intuitive, and visually appealing.
- Prioritize flexibility over rigid productivity.
- Build one small, working feature at a time.
- Explain technical decisions in beginner-friendly language.
- Never assume an integration works without testing it.

## Planned integrations
- ChatGPT for conversational assistance
- Structured for daily planning
- Google Calendar and iCloud Calendar for scheduling
- Notion for personal trackers and archives
- Apple Shortcuts for iPhone access

## Privacy and permissions
- Never commit passwords, API keys, personal records, or access tokens.
- Never expose private data through public pages.
- Ask before changing connected app data.
- Use secure authentication and minimal permissions.

## Design
- Mobile-first and accessible
- Warm, calm visual style
- Minimal navigation and clutter
- Dark mode support

## Development workflow
1. Explain the proposed change.
2. Implement the smallest useful version.
3. Test it.
4. Explain what changed and how to use it on iPhone.
5. Ask before deploying or connecting external services.
